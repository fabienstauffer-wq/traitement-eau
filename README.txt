1. Dans Supabase > SQL Editor, exécuter le fichier installation_eau_supabase.sql fourni séparément.
2. Dans GitHub, remplacer le fichier index.html à la racine du dépôt traitement-eau par celui-ci.
3. Supprimer les anciens fichiers app.js et config.js si inutilisés.
4. Dans Supabase Authentication > URL Configuration, ajouter https://fabienstauffer-wq.github.io/traitement-eau/ aux Redirect URLs.
5. Tester la consultation, puis la connexion administrateur et un ajout.
